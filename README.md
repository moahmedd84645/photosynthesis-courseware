# منصة مختبر البناء الضوئي ثلاثية الأبعاد (Interactive E-Learning Courseware)

منصة تعليمية ذاتية متكاملة قائمة على الويب ومبنية بفلسفة **"التعلم للإتقان" (Mastery Learning)** والمحاكاة التفاعلية ثلاثية الأبعاد.

## المزايا الرئيسية:
1. **ألعاب ومحاكاة معملية 3D حقيقية**:
   - **المحطة 1:** لغز شجرة الصفصاف وتجربة فان هيلمونت مع ميزان الكتل الرقمي وتسريع الزمن 5 سنوات.
   - **المحطة 2:** تشريح البلاستيدة الخضراء ثلاثي الأبعاد ومعمل كشافات الضوء وتدفق الفوتونات.
   - **المحطة 3:** خط إنتاج الطاقة الحيوي (شطر الماء - شحن ATP - تثبيت ثاني أكسيد الكربون وإنتاج سكر الجلوكوز).
   - **المحطة 4:** بروتوكول كاشف النشا واليود بمراحله الأربع مع الزراعة العمودية.
2. **المحطة 5 للتقويم الختامي فقط**:
   - أسئلة تفكير عليا (HOTS) مستمدة من بنك الأسئلة المعتمد.
   - إصدار شهادة إتقان وتفوق علمي رقمية فورية معتمدة قابلة للطباعة والتنزيل.
3. **الدرج الذكي لعلاج التعثر (Smart Remedial Drawer)**:
   - ينزلق عند أي تعثر لتقديم تلميح ذكي وتأصيل علمي دقيق بدون خصم أي درجات.
4. **تفريد التعلم (Adaptive Learning)**:
   - مسار تأسيسي شامل ومسار لتحدي المتفوقين.
5. **لوحة تحكم وإشراف المعلم (`teacher.html`)**:
   - متابعة حية ومباشرة للطلاب عبر قاعدة بيانات **Firebase Firestore**.
   - التحكم في إتاحة وقفل المحطات.
6. **خلو تام من الإيموجي**:
   - استخدام أيقونات خطية راقية من `Lucide Icons`.
   - باليت ألوان معملية فاتحة راقية (Emerald Green, Clean Slate, Amber Gold).
